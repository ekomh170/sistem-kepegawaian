# Panduan Alur Penggunaan (Aktor Karyawan)
## Sistem Informasi Kepegawaian — CV Boss Muda Mandiri

Dokumen ini menjelaskan langkah-langkah praktis bagi Karyawan dalam menggunakan aplikasi mobile untuk kegiatan harian.

---

## 1. Siklus Harian Karyawan (Flow Utama)

Banyak yang bingung apakah presensi dilakukan per tugas atau per hari. Jawabannya: **Presensi dilakukan 1x sehari di Kantor Pusat.**

### Langkah 1: Absensi Masuk (Check-in)
- **Lokasi**: Halaman Beranda (Blok Atas).
- **Waktu**: Pagi hari saat sampai di Kantor Pusat (sebelum jam 08:10 agar tidak kena potongan).
- **Aksi**: Klik "Presensi Masuk" → Ambil Lokasi GPS → Ambil Foto Selfie → Kirim.
- **Hasil**: Status harian Anda menjadi "HADIR" atau "TERLAMBAT".

### Langkah 2: Merespon Tugas (Konfirmasi)
- **Lokasi**: Menu **Tugas** (Navigasi Bawah).
- **Aksi**: Anda akan melihat daftar tugas (misal: Tugas Pagi, Siang, Sore).
- **Penting**: Klik tombol **"Terima Tugas"** pada setiap tugas yang diberikan Admin. Status harus berubah menjadi "DITERIMA" agar Anda bisa mengunggah bukti nantinya.

### Langkah 3: Melaporkan Hasil Kerja (Upload Bukti)
- **Lokasi**: Menu **Tugas** → Pilih tugas yang sudah selesai.
- **Aksi**: Klik **"Upload Bukti Pekerjaan"**.
- **Dokumentasi**: Ambil **Foto Before** (sebelum dikerjakan) dan **Foto After** (sesudah selesai) + isi keterangan singkat.
- **Catatan**: Jika ada 3 tugas, maka Anda mengunggah bukti 3 kali secara terpisah.

### Langkah 4: Absensi Pulang (Check-out)
- **Lokasi**: Halaman Beranda (Blok Atas).
- **Waktu**: Sore hari sebelum pulang dari kantor.
- **Aksi**: Klik "Presensi Pulang" → Kirim.
- **Hasil**: Durasi kerja harian Anda akan dihitung otomatis.

## 2. Tanya Jawab Cepat (FAQ)

**P: Saya sudah check-in di Beranda, kenapa di menu Tugas masih "Menunggu"?**
J: Check-in di Beranda adalah absensi kehadiran harian. Sedangkan di menu Tugas, Anda harus menekan tombol "Terima Tugas" secara manual sebagai komitmen bahwa Anda mengerjakan tugas tersebut.

**P: Apakah saya bisa upload bukti kalau belum check-in?**
J: Bisa. Laporan tugas (Bukti Pekerjaan) tidak terkunci oleh absensi harian, sehingga jika Anda langsung ke lapangan, Anda tetap bisa melaporkan hasil kerja. Namun, absensi harian tetap wajib dilakukan di Kantor Pusat untuk perhitungan gaji/kehadiran.

**P: Kenapa tombol "Upload Bukti" tidak muncul?**
J: Pastikan status tugas sudah **"DITERIMA"**. Jika masih "MENUNGGU", tombol upload tidak akan muncul.

**P: Dimana saya melihat riwayat absensi saya?**
J: Buka menu **Riwayat** di navigasi bawah. Anda bisa melihat status hadir, telat, dan estimasi potongan bulan berjalan.
